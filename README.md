ข้อ 2.1 อธิบายความแตกต่างระหว่าง คลาส กับ อ็อบเจกต์ พร้อมยกตัวอย่างจากระบบฟิตเนสอย่างละ 1 ตัวอย่าง

คำตอบ: คลาส (Class) คือ "แม่พิมพ์" หรือโครงสร้างต้นแบบที่กำหนดว่าสิ่งนั้นมีข้อมูลและทำอะไรได้บ้าง ส่วน อ็อบเจกต์ (Object) คือ "ตัวตนจริง" ที่ถูกสร้างขึ้นมาจากแม่พิมพ์นั้น
ตัวอย่างคลาส: Member (คลาสสมาชิกฟิตเนส ที่มีข้อมูลชื่อและวันหมดอายุ)
ตัวอย่างอ็อบเจกต์: member_somchai (สมาชิกตัวจริงที่ชื่อ "สมชาย" วันหมดอายุ 31 ธ.ค. 2026)

ข้อ 2.2 อ่านประโยคนี้ แล้วขีดเส้นใต้คำนามและคำกริยา จากนั้นเสนอคลาสอย่างน้อย 3 คลาส และเมธอดอย่างน้อย 2 เมธอด
ประโยค: ร้านกาแฟ รับ ออเดอร์ จาก ลูกค้า และ คิดเงิน ตาม รายการเครื่องดื่ม
คำนาม: ร้านกาแฟ, ออเดอร์, ลูกค้า, รายการเครื่องดื่ม (นำมาใช้สร้างเป็นคลาสและแอตทริบิวต์)
คำกริยา: รับ (ออเดอร์), คิดเงิน (นำมาใช้สร้างเป็นเมธอด)
คลาสที่เสนอ: Cafe (ร้านกาแฟ), Customer (ลูกค้า), Order (ออเดอร์), Drink (เครื่องดื่ม)
เมธอดที่เสนอ: take_order() (รับออเดอร์), calculate_total() (คิดเงิน)

ข้อ 2.3 เขียนข้อดี 2 ข้อของการเก็บข้อมูลและเมธอดไว้ในคลาสเดียวกัน เมื่อเทียบกับการแยกตัวแปรและฟังก์ชัน
คำตอบ:
จัดระเบียบโค้ดง่ายและค้นหาสะดวก: ข้อมูลและฟังก์ชันที่ทำงานเกี่ยวข้องกันถูกจัดกลุ่มรวมไว้เป็นก้อนเดียว ทำให้ดูแลรักษาและแก้ไขได้ง่ายในอนาคต
ป้องกันการแก้ไขข้อมูลโดยไม่ตั้งใจ (ความปลอดภัยของข้อมูล): สามารถควบคุมการเข้าถึงข้อมูลได้ ทำให้ข้อมูลภายในไม่ถูกฟังก์ชันภายนอกแก้ไขจนผิดพลาด

ข้อ 2.4 ในเมธอดของคลาส คำว่า self หมายถึงอะไร (1-2 ประโยค)
คำตอบ: self หมายถึง ตัวอ็อบเจกต์นั้น ๆ เอง ที่กำลังเรียกใช้งานเมธอดอยู่ในขณะนั้น ใช้สำหรับอ้างอิงเพื่อเข้าถึงตัวแปร (attribute) หรือเมธอดอื่น ๆ ที่อยู่ภายในอ็อบเจกต์ตัวเดียวกัน

ข้อ 2.5 จับคู่คำศัพท์กับความหมาย โดยเขียนตัวอักษร ก-ง ลงในช่องว่าง
คลาส ข. แม่แบบสำหรับสร้างอ็อบเจกต์ : คือโครงสร้างต้นแบบหรือพิมพ์เขียว
อ็อบเจกต์ ง. สิ่งที่สร้างขึ้นจากแม่แบบ : คือตัวตนจริงที่ถูกสร้างมาจากคลาส
แอตทริบิวต์ ก. ข้อมูลที่อ็อบเจกต์เก็บไว้ : คือคุณลักษณะหรือตัวแปรของอ็อบเจกต์นั้น
เมธอด ค. สิ่งที่อ็อบเจกต์ทำได้ : คือพฤติกรรมหรือฟังก์ชันการทำงานของอ็อบเจกต์นั้น
